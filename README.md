# 픽셀 VTuber — 퇴근여우

## OBS에서 쓰기 (Windows)

OBS 브라우저 소스와 크롬은 **서로 다른 프로그램**입니다. `localStorage`와 `BroadcastChannel`은 넘어가지 않습니다. 표정과 음악 상태는 이 PC 안의 중계(`127.0.0.1`)로만 전달합니다. 카메라 영상과 마이크 소리는 나가지 않습니다.

중계를 켜지 않으면 예전처럼 페이지 하나가 카메라·음악을 직접 처리합니다. GitHub Pages 주소에서는 분리 모드가 동작하지 않습니다. 브라우저가 `https://…` 페이지에서 `ws://127.0.0.1` 접속을 막기 때문입니다.

```bat
start-vtuber.bat
```

또는 프로젝트 폴더에서:

```bat
py -3 tools\vtuber_relay.py
```

`python`만 되면 `python tools\vtuber_relay.py` 도 같습니다. 기본 포트는 8765입니다. 주소는 반드시 `127.0.0.1` 입니다. `localhost`가 IPv6(`::1`)로만 열리면 연결되지 않습니다.

### 캐릭터 (얼굴 추적)

1. 크롬에서 추적 주소를 열고 **카메라 시작**. 필요하면 마이크도 켭니다. 이 창을 최소화하지 마세요.
2. OBS → 소스 추가 → 브라우저. 너비 1280, 높이 720. 아래 표시 주소를 넣습니다.
3. 추적 창의 「OBS 주소 복사」를 써도 됩니다.

- 추적: `http://127.0.0.1:8765/?role=track&char=fox93`
- OBS: `http://127.0.0.1:8765/?role=display&obs=1&char=fox93`

`?role=display` 페이지는 `getUserMedia`를 호출하지 않습니다. 예전 주소(`?obs=1`만, 역할 없음)는 OBS가 카메라를 직접 여는 방식이라 대부분 실패합니다.

위치·크기는 OBS 주소의 `x` `y` `z` 또는 OBS 변환으로 맞춥니다. 추적 창의 드래그는 OBS 쪽으로 따라가지 않습니다.

### 음악 플레이어

플레이어는 카메라를 쓰지 않습니다. 막히는 지점은 따로입니다. 볼륨·마지막 카테고리는 그 브라우저의 `localStorage`에만 있고, 단축키는 그 창이 포커스를 가져야 합니다. OBS 소스에는 키보드가 거의 들어가지 않습니다. 두 페이지가 각자 재생하면 소리가 두 번 납니다.

조작의 기준은 **크롬 조작 페이지**입니다. 곡, 재생/일시정지, 다음, 카테고리, 셔플, 볼륨, 재생 위치를 그 페이지가 정합니다. OBS 페이지는 그걸 따라 그림(헤드폰·진행 막대)을 그리고, 중계가 고른 **한 곳**만 소리를 냅니다. 기본은 OBS 표시 페이지입니다. OBS가 자동재생을 막으면 조작 페이지가 소리를 맡고, OBS에는 「상호작용」으로 한 번 눌러 달라는 안내가 나옵니다.

- 조작: `http://127.0.0.1:8765/player/?role=control&shuffle=1&vol=0.5`
- OBS: `http://127.0.0.1:8765/player/?role=display&obs=1`

방송 믹서에 음악을 넣으려면 OBS 브라우저 소스에서 **OBS에서 오디오 제어**(Control audio via OBS)를 켭니다. 그때 크롬 쪽은 음소거이므로 크롬 소리까지 캡처하면 겹칩니다. 표시 창이 아직 없을 때는 조작 페이지가 들리고, OBS가 연결되면 조작 페이지가 음소거됩니다.

`?cat=오프닝` 은 카테고리 이름이 아닙니다. 출근 도장(`opening`)으로 연결됩니다. 예전 주소 `http://127.0.0.1:8765/player/?obs=1&cat=오프닝&shuffle=1&vol=0.5` 는 중계 없이 그 페이지 혼자 재생합니다. GitHub Pages의 같은 쿼리도 혼자 재생하는 예전 동작입니다.

헤드폰 그림은 플레이어 카드 스킨(`skin`을 빼면 카드)이 재생 중일 때의 표시입니다. VTuber 얼굴 페이지는 음악 상태를 읽지 않습니다. 둘은 중계 방만 다르고(`vtuber` / `player`) 서로 표정을 바꾸지 않습니다.

### 확인하지 못한 것 / 한계

이 저장소를 만든 환경에는 OBS가 없습니다. OBS 안에서 카메라 권한, 투명 배경, 자동재생이 실제로 어떻게 나오는지는 여기서 확인하지 않았습니다. Chromium은 사용자 클릭 없이 소리 있는 재생을 막을 수 있고, 일부 OBS 버전은 브라우저 소스에 자동재생을 허용합니다. 소리가 없으면 소스 우클릭 → **상호작용** → 재생 버튼을 한 번 누르세요.

추적 창을 최소화하면 브라우저가 카메라 루프를 늦출 수 있습니다. 추적 쪽은 카메라를 켠 뒤 무음 오디오로 절전을 줄이지만, 창은 켜 두는 편이 안전합니다.

중계를 끄면 표시 페이지는 다시 연결을 시도하고, 그동안 캐릭터는 자동 눈깜빡임만 합니다. 음악은 끊겼다 이어집니다.

## 마이크 신남 감지
'🎤 마이크 켜기'를 누르면 음량(최근 10초 자동 보정)·음높이(본인 평균 대비)·에너지 변동으로 신남 점수(0~1)를 계산합니다. 신날수록 귀가 계단식으로 들썩이고 꼬리(24프레임)는 6가지 패턴(느긋한 큰 흔들기·가운데 살랑살랑·휙휙 두 번·한쪽으로 말고 버티다 풀기·크게 휙+멈춤·끝만 빠르게 파닥) 중 신남 정도에 따라 가중치 랜덤으로 고릅니다(같은 패턴 3연속 금지). 신날수록 휙휙/파닥이 잦아지고 템포가 서서히 빨라집니다, 아주 신나면 통통 튀고 반짝이가 추가됩니다. 0.7초 이상 신나면 표정이 '웃음+반짝'으로 바뀝니다(체크 해제로 끄기, 얼굴 추적 놀람이 우선). '신남 감도' 슬라이더로 조절. 마이크는 브라우저 밖으로 전송되지 않습니다.
