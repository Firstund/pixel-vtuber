# 픽셀 VTuber — 퇴근여우
정적 파일: index.html, style.css, js/app.js, assets/<캐릭터>/ (manifest.json + PNG 시트)

- `assets/fox53/` 퇴근여우 v5.3: v5.2 + 가디건 빈틈/흰 줄 메움, 목 좁힘·턱 그림자.
- `assets/fox52/` 퇴근여우 v5.2: v5.1 머리카락·몸(얼굴 비운 단색 피부) + v3식 깔끔한 눈/입/눈썹 레이어 합성. 귀 레이어 들썩임 유지.
- `assets/fox51/` 퇴근여우 v5.1: v5와 같은 선·레이어에 v3 톤의 단색 팔레트(17색, 재질별 기본+그림자 1단) 적용, 잡티 제거.
- `assets/fox5/` 퇴근여우 v5: v4 시트를 다시 픽셀화(32색, 블록 최빈값 축소 + 잡티 제거 + 1px 외곽선). 레이어: `base`(표정 6열, 귀 뺌) · `ears`(들썩임) · `mouth`(표정×벌림 3단계 = 18열) · `blink`(표정별 감은 눈) · 꼬리 24프레임. 행 = 각도 15.
- `assets/fox4/` 퇴근여우 v4: 제미나이 재해석 시트를 128px 픽셀화한 통짜 프레임(`frames.png`: 행 = 각도 15, 열 = 표정 6 × [뜬 눈, 깜빡임]). 꼬리는 별도 24프레임 레이어.
- `assets/fox3/` 퇴근여우 v3 (128px). 같은 각도 시트 구조.
- `assets/fox2/` 퇴근여우 v2 (96px). 머리 레이어는 각도 시트: 행 = (pitch+1)*5 + (yaw+2), yaw −2…+2(+ = 화면 오른쪽을 봄), pitch −1 위 / 0 / +1 아래
  - eyes: 기본·반눈·감음·웃음·피곤·놀람·의기양양 / mouth: :3·살짝·크게·미소·O·경악·의기양양 / brows: 기본·올림·걱정·한쪽올림 / ears: 서있음·처짐 / tail 4 / sparkle 3
- `assets/test/` 구버전 64px 테스트 캐릭터
- 생성 스크립트: tools/ (gen_v2.py, gen_angles.py, preview_angles.py, gen_sprites_test.py)

머리 회전: 각도를 단계로 양자화(데드존 히스테리시스) → "끊김 느낌" 켜면 애니메이션 fps(6–30)로만 갱신 + 단계당 최소 100ms 유지. 입/눈 깜빡임은 매 프레임 반응.
롤(기울기)은 ±9° 3단계, 원본 해상도에서 최근접 보간으로 회전 후 정수 배율 확대.

로컬 실행: `python3 -m http.server 8765` → http://localhost:8765 (카메라는 localhost 또는 HTTPS에서만 동작)
URL 옵션: ?demo=1 (카메라 없이 각도·표정 순환), ?char=test, ?mirror=0, ?choppy=0, ?clean=1, ?bg=00ff00
단축키: 1–5 표정, h 클린 뷰, Esc/더블탭 해제

## 마이크 신남 감지
'🎤 마이크 켜기'를 누르면 음량(최근 10초 자동 보정)·음높이(본인 평균 대비)·에너지 변동으로 신남 점수(0~1)를 계산합니다. 신날수록 귀가 계단식으로 들썩이고 꼬리(24프레임)는 6가지 패턴(느긋한 큰 흔들기·가운데 살랑살랑·휙휙 두 번·한쪽으로 말고 버티다 풀기·크게 휙+멈춤·끝만 빠르게 파닥) 중 신남 정도에 따라 가중치 랜덤으로 고릅니다(같은 패턴 3연속 금지). 신날수록 휙휙/파닥이 잦아지고 템포가 서서히 빨라집니다, 아주 신나면 통통 튀고 반짝이가 추가됩니다. 0.7초 이상 신나면 표정이 '웃음+반짝'으로 바뀝니다(체크 해제로 끄기, 얼굴 추적 놀람이 우선). '신남 감도' 슬라이더로 조절. 마이크는 브라우저 밖으로 전송되지 않습니다.
